MI-GAN-512-Places2 ONNX inference pipeline.

Files (a single 26.78 MB ONNX file split in two, joined in the browser, because
the deploy target rejects any file over 25 MiB):
  migan-512-places2.part1.onnx
  migan-512-places2.part2.onnx

Source: https://huggingface.co/andraniksargsyan/migan (migan_pipeline_v2.onnx),
published by the paper's first author and linked from the project README as the
pre-converted pipeline for application use.
Project: https://github.com/Picsart-AI-Research/MI-GAN
Paper: MI-GAN: A Simple Baseline for Image Inpainting on Mobile Devices,
Sargsyan, Navasardyan, Xu, Shi - ICCV 2023 (arXiv:2312.05284)
